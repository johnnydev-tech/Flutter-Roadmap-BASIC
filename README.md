
# 🚀 Flutter Roadmap: A Rota Definitiva para o Domínio do Flutter

![GitHub stars](https://img.shields.io/github/stars/johnnydev-tech/Flutter-Roadmap-BASIC?style=social)

### Chega de se sentir perdido. Conquiste o Flutter de uma vez por todas.

Você já sentiu a frustração de não saber o que estudar em seguida? Ou a confusão de ter um milhão de tutoriais e nenhum caminho claro? **Esse sentimento acaba hoje.**

Este não é apenas mais um roadmap. É a **rota definitiva**, um guia prático e estratégico de 6 meses, desenhado para transformar você em um desenvolvedor Flutter confiante e preparado para o mercado. Nós eliminamos o ruído para que você possa focar no que realmente importa: **construir, aprender e evoluir.**

---

## 🔥 Por que Este Roadmap é Diferente?

Muitos roadmaps são apenas listas de tecnologias. O nosso é um **plano de ação.**

*   **Foco em Projetos Práticos:** A cada 2 semanas, você não apenas estuda a teoria, mas a aplica na construção de um aplicativo real. Do clone do Nubank a um app de chat com Firebase, você constrói um portfólio enquanto aprende.
*   **Curva de Aprendizagem Otimizada:** A estrutura foi pensada para que cada novo conceito se baseie no anterior, criando uma base sólida e evitando a sobrecarga de informação.
*   **Conteúdo Direto ao Ponto:** Sem enrolação. Focamos nas ferramentas e conceitos que o mercado de trabalho exige, com links diretos para a documentação oficial e os melhores recursos da comunidade.
*   **Comunidade e Suporte:** Você não está sozinho. Junte-se à nossa [comunidade no Discord](https://discord.gg/9eqHSb32) para tirar dúvidas, compartilhar seu progresso e fazer networking com outros desenvolvedores.

## 🗺️ Visão Geral do Roadmap: Sua Jornada de 6 Meses

| Mês | Semana | Tema | Teoria | App Prático | Documentação |
| --- | --- | --- | --- | --- | --- |
| 1 | 1-2 | Introdução ao Flutter | - Instalação do Flutter e configuração do ambiente<br>- Estrutura básica de um projeto Flutter<br>- Widgets básicos (Text, Container, Row, Column) | "Hello World" customizado | [Get started](https://docs.flutter.dev/get-started/install) |
| 1 | 3-4 | Widgets e Navegação | - Navegação entre telas (Navigator)<br>- Estrutura de navegação e rotas<br>- Widgets de estado (Stateful e Stateless) | Clone da interface do Nubank | [Widget catalog](https://docs.flutter.dev/ui/widgets), [Navigation and routing](https://docs.flutter.dev/ui/navigation) |
| 2 | 5-6 | Layouts Avançados | - Flexbox e layouts responsivos<br>- ListView e GridView<br>- MediaQuery e adaptação para diferentes tamanhos de tela | Calculadora de IMC | [Layouts in Flutter](https://docs.flutter.dev/ui/layout) |
| 2 | 7-8 | Formulários e Validações | - Formulários e input de usuário<br>- Validação de formulários<br>- Gerenciamento de estado básico (setState) | Verificador de combustível | [Building a form with validation](https://docs.flutter.dev/cookbook/forms/validation) |
| 3 | 9-10 | Consumo de APIs | - HTTP requests com o pacote `http`<br>- Parsing de JSON<br>- Gerenciamento de dados assíncronos (FutureBuilder) | Consulta de CEP (ViaCep) | [Networking](https://docs.flutter.dev/data-and-backend/networking) |
| 3 | 11-12 | Persistência de Dados | - Armazenamento local com SharedPreferences<br>- Persistência de dados em arquivos<br>- Introdução ao SQLite e bancos de dados locais | Lista de Tarefas (To-Do List) | [Persistence](https://docs.flutter.dev/data-and-backend/persistence) |
| 4 | 13-14 | Estilização e Temas | - Temas e customização de widgets<br>- Uso de fontes e ícones personalizados<br>- Dark mode e light mode | App de clima com tema | [Theming](https://docs.flutter.dev/ui/theme) |
| 4 | 15-16 | Animações | - Animações básicas (AnimatedContainer, AnimatedOpacity)<br>- Animações com o AnimationController<br>- Animações complexas (Hero animations) | App com animações de transição | [Introduction to animations](https://docs.flutter.dev/ui/animations) |
| 5 | 17-18 | Gerenciamento de Estado | - Introdução ao Provider<br>- Uso de Riverpod e outras bibliotecas de gerenciamento de estado | App de controle de despesas | [State management](https://docs.flutter.dev/data-and-backend/state-mgmt/options) |
| 5 | 19-20 | Integração com Firebase | - Autenticação com Firebase Auth<br>- Armazenamento de dados com Firestore<br>- Push notifications com Firebase Cloud Messaging | Chat simples com autenticação | [Add Firebase to your Flutter app](https://firebase.google.com/docs/flutter/setup) |
| 6 | 21-22 | Testes e Debugging | - Testes de widgets e integração<br>- Debugging e profiling<br>- Melhorias de desempenho | App de cotação do Bitcoin | [Testing Flutter apps](https://docs.flutter.dev/testing) |
| 6 | 23-24 | Projeto Final | - Revisão de conceitos aprendidos<br>- Planejamento e design do aplicativo final | App de finanças pessoais | - |
| 6 | 25-26 | Arquitetura e Clean Code | - Princípios da Arquitetura SOLID<br>- Introdução à Clean Architecture com Reso Coder<br>- Clean Dart e melhores práticas | Projeto com Clean Architecture | [Guide to app architecture](https://docs.flutter.dev/architecture) |

## 🌟 Como Contribuir e Engajar

Este é um projeto open-source e sua ajuda é muito bem-vinda! Aqui estão algumas formas de contribuir:

1.  **Dê uma Estrela no Repositório:** A maneira mais simples de nos apoiar! Uma estrela ajuda a dar mais visibilidade ao projeto e motiva a continuar evoluindo o roadmap.
    
    [![GitHub stars](https://img.shields.io/github/stars/johnnydev-tech/Flutter-Roadmap-BASIC?style=social)](https://github.com/johnnydev-tech/Flutter-Roadmap-BASIC/stargazers)

2.  **Abra uma Issue:** Encontrou um erro, um link quebrado ou tem uma sugestão para melhorar o roadmap? [Abra uma issue](https://github.com/johnnydev-tech/Flutter-Roadmap-BASIC/issues) e vamos conversar sobre isso.

3.  **Envie um Pull Request:** Se você quer adicionar um novo recurso, um app de exemplo ou corrigir algo, [envie um Pull Request](https://github.com/johnnydev-tech/Flutter-Roadmap-BASIC/pulls). Toda contribuição é valorizada.

### Compartilhe sua Evolução

Sugerimos que você compartilhe os códigos desenvolvidos durante esse processo através do GitHub. Isso pode auxiliar na análise de sua evolução a cada 2 semanas e também servirá como um ótimo portfólio.

-   **Usuário para Revisão (Opcional):** [@johnnydev-tech](https://github.com/johnnydev-tech)
-   **Instruções:** Para compartilhar, suba todos os códigos para o GitHub em modo público e, se desejar, adicione o usuário acima como revisor para acompanhar a evolução.
